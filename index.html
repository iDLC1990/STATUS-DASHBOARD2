Чтобы таблица гарантированно была по центру экрана (и по горизонтали, и по вертикали) и при этом не обрезалась, лучше всего использовать современный CSS Flexbox и свойство object-fit (или scale через CSS). Вот как нужно изменить ваш код, чтобы добиться идеального центрирования: 1. Измените стили CSS Замените блок стилей для .table-container и добавьте специальный класс для "режима презентации": CSS /* Основной контейнер для центрирования */ .table-container { width: 90%; /* Немного увеличим для красоты */ margin: 24px auto; display: flex; flex-direction: column; align-items: center; /* Центровка по горизонтали */ } /* Обертка для таблиц, чтобы они не расползались */ #overview-block, #diag-block { width: 100%; } /* Тот самый контейнер, который мы хотим видеть по центру всего экрана */ .full-screen-center { position: fixed; top: 50%; left: 50%; transform: translate(-50%, -50%); /* Магия центрирования по вертикали и горизонтали */ width: 95vw; height: 90vh; display: flex; flex-direction: column; justify-content: center; align-items: center; z-index: 999; background: rgba(0, 0, 0, 0.8); /* Темный фон, чтобы акцентировать внимание */ padding: 20px; box-sizing: border-box; } /* Чтобы таблица внутри не обрезалась и сжималась под размер */ #combined-table { max-width: 100%; max-height: 80vh; object-fit: contain; border-collapse: collapse; } 2. Обновите логику клика в JavaScript Замените вашу функцию document.getElementById('main-title').onclick на эту. Она будет добавлять/удалять класс центрирования: JavaScript document.getElementById('main-title').onclick = () => { const overviewBlock = document.getElementById('overview-block'); const tableContainer = overviewBlock.closest('.table-container'); const diagContainer = document.getElementById('diag-block').parentElement; // Переключаем режим "На весь экран" if (!tableContainer.classList.contains('full-screen-center')) { // ВКЛЮЧАЕМ ЦЕНТРИРОВАНИЕ tableContainer.classList.add('full-screen-center'); diagContainer.style.display = 'none'; // Прячем нижнюю таблицу overviewBlock.style.display = 'block'; } else { // ВЫКЛЮЧАЕМ (возврат в обычный вид) tableContainer.classList.remove('full-screen-center'); diagContainer.style.display = 'block'; } }; Что это даст: По вертикали: top: 50% + transform: translateY(-50%) выровняет таблицу ровно по центру высоты монитора, независимо от его разрешения. По ширине: Таблица будет стремиться занять центр благодаря left: 50%. Без обрезки: Свойства max-width и max-height не дадут таблице вылезти за пределы экрана.
